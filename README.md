# Termometro Escola Sabatina

Aplicativo web para acompanhar indicadores da Escola Sabatina, visualizar o termometro de desempenho e exportar relatorios em PDF.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Como Contribuir

Melhorias sao bem-vindas por Pull Request.

1. Faca um fork do repositorio.
2. Crie uma branch para sua melhoria.
3. Rode `npm install`, `npm run lint` e `npm run build`.
4. Abra um Pull Request explicando o que mudou e por que a melhoria ajuda o app.

As alteracoes entram somente depois de revisao e aprovacao do mantenedor.
