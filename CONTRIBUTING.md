# Como contribuir

Obrigado por ajudar a melhorar o Termometro Escola Sabatina.

## Fluxo recomendado

1. Abra uma issue ou descreva claramente a melhoria no Pull Request.
2. Crie uma branch com um nome curto, por exemplo `melhoria/exportacao-pdf`.
3. Faca alteracoes pequenas e focadas.
4. Antes de enviar, rode:

```powershell
npm run lint
npm run build
```

## Regras para Pull Requests

- Explique o problema que foi resolvido.
- Informe quais telas ou fluxos foram afetados.
- Inclua prints quando a mudanca for visual.
- Nao envie `node_modules`, `dist`, arquivos `.env` ou arquivos `.zip`.
- Aguarde aprovacao do mantenedor antes do merge.
